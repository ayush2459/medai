# MedIntel AI

MedIntel AI is a healthcare operations and clinical risk dashboard project with a React/Vite frontend and FastAPI backend.

## Project structure

- `frontend/` — React, TypeScript, and Vite UI
- `backend/` — FastAPI application, patient and analytics APIs, authentication, database models, and ICU risk inference
- `docker-compose.yml` — local multi-service setup

See the frontend and backend README/configuration files for setup details. Copy `.env.example` to `.env` and configure local environment values before running. Do not commit credentials or real patient information.
